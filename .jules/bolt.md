## 2024-05-24 - React Context Re-renders Nullifying React.memo
**Learning:** In React, if a memoized component (e.g. `PackageCard = React.memo(...)`) consumes a context via `useWaypoint()`, it will still completely re-render whenever the Context Provider's value object changes. Because `WaypointProvider` generates a new object literal for its `value` prop on every render (due to state changes like toasts or selected packages), all consuming components re-render, effectively bypassing `React.memo()`.
**Action:** When attempting to memoize list item components, also verify if they directly consume a frequently-updating context. If they do, fixing the list item requires either deeply memoizing the Provider's `value` object using `useMemo` (with appropriately memoized functions via `useCallback`), or refactoring the list items to take context-derived functions directly as props rather than calling the context hook themselves.
